# Zournel

A Flutter-based journal application that allows users to securely create and manage personal journal entries using Firebase services.

## Features

* User authentication with Firebase Authentication
* Create journal entries with title and description
* Edit existing journal entries
* Delete journal entries
* Cloud data storage using Firebase Firestore
* Responsive and user-friendly Flutter UI

## Tech Stack

* Flutter
* Dart
* Firebase Authentication
* Cloud Firestore

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/zournel.git
```

2. Navigate to the project directory:

```bash
cd zournel
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```

This project was developed to practice Flutter development and Firebase integration, including authentication and CRUD (Create, Read, Update, Delete) operations using Cloud Firestore.
